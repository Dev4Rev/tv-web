# Dev4Rev TV

[English](README.en.md) · [Русский](README.md)

**Dev4Rev TV** — статический медиаплеер для просмотра публичных M3U-плейлистов прямо в браузере. Проект не требует сборки, серверной части или API: вся логика работает на HTML, CSS и ванильном JavaScript.

## Что это простыми словами

Откройте страницу — и перед вами телевизор и кинотеатр в одном окне. Можно смотреть каналы из готовых тематических подборок или вставить собственную ссылку на плейлист. Всё работает в браузере, без установки дополнительных приложений.

Технически это демонстрация клиентского плеера и системы подборок. Репозиторий содержит код сайта и M3U-файлы со ссылками на публично доступные медиаресурсы. Видеофайлы на хостинге проекта не хранятся: плеер воспроизводит только то, что доступно по указанным адресам. Плейлисты с полными неофициальными записями помечены в интерфейсе меткой «НЕОФИЦИАЛЬНО».

## Возможности

- Плеер с поддержкой HLS, DASH, MPEG-TS и обычного видео, PiP, мини-плеером и полноэкранным режимом.
- Живая подсветка вокруг видео: цвета берутся из текущего кадра (для CORS-доступных потоков) или из палитры подборки.
- Поиск по каналам и плейлистам, избранное, пользовательские подборки и загрузка собственного M3U — всё хранится локально в браузере.
- Поддержка `magnet:`-ссылок и локальных `.torrent`-файлов через встроенный WebTorrent (для легальных раздач с web-сидами).
- Адаптивный интерфейс: удобно на телефоне, планшете и десктопе, с учётом safe-area и короткого ландшафта.
- Отдельные страницы политики обработки данных и ошибки 404, публичные адреса без `.html`.

## Структура

```text
index.html                       Разметка страницы и плеера
assets/css/main.css              Стили, адаптация, cinema-режим
assets/js/                       Логика плеера, плейлистов и подборок
assets/data/collections.json     Описание подборок и плейлистов
assets/data/search-index.json    Индекс для поиска
assets/data/collections/*.m3u    Встроенные плейлисты
assets/data/torrents/*.torrent   Файлы метаданных раздач
privacy.html, 404.html           Политика и страница ошибки
CNAME                            Кастомный домен
```

## Локальный просмотр

С Docker:

```bash
docker compose up -d --build
# открыть http://localhost:999/
```

Без Docker — `python serve.py`. Он же отдаёт `404.html` для неизвестных адресов. Обычный `python -m http.server 999` не поддерживает кастомную 404, поэтому проверять редирект через него нельзя.

## Публикация

Это обычный статический сайт: опубликуйте содержимое корня репозитория через GitHub Pages (ветка `main`, корень `/`) или скопируйте файлы на любой статический хостинг. `CNAME` задаёт домен `tv.dev4rev.ru`, каноническая ссылка в `index.html` указывает на него же.

Внутренние пути записаны относительно (`./assets/...`), но `<base href="/">` привязывает их к корню домена — это нужно, чтобы ассеты и 404 работали и при fallback с вложенного адреса. Сайт рассчитан на публикацию в корне домена.

## Дисклеймер

Проект является технической демонстрацией и не является хранилищем видеоконтента. Все ссылки ведут на сторонние публичные ресурсы; доступность и законность конкретных материалов определяются их владельцами и законодательством применимой юрисдикции. Пользователь самостоятельно решает, какие потоки открывать. Метки в интерфейсе помогают отличить официальные материалы от неофициальных.
