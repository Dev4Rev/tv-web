# dev4rev TV

Статический TV/cinema-сайт с плейлистами, каналами и плеером. Не требует сборки, серверной части или API: всё работает на HTML, CSS и ванильном JavaScript.

## Что внутри

- 25 подборок и 49 встроенных M3U-плейлистов (`assets/data/collections/`), включая «Шрек — весь цикл» и «Гарри Поттер — весь цикл» с официальными трейлерами и промо и подборку «Открытое кино · торренты».
- Плеер с поддержкой HLS, DASH, MPEG-TS и нативного видео, PiP, мини-плеером и полноэкранным режимом.
- Живая подсветка вокруг плеера: цвета берутся из текущего кадра видео (`assets/js/ambient.js`), при недоступности кадра — из палитры подборки.
- Поиск каналов, избранное, пользовательские подборки и загрузка своих M3U — всё хранится в `localStorage`.
- Канонические ссылки на плейлисты вида `https://tv.dev4rev.ru/assets/data/collections/....m3u` (домен задан в `CNAME`).

## Структура

```text
index.html                 Разметка страницы и плеера
assets/css/main.css        Стили, адаптация и cinema-режим
assets/js/                 Логика плеера, плейлистов, подборок и подсветки
assets/data/collections.json    Описание подборок
assets/data/search-index.json   Индекс каналов для поиска
assets/data/collections/*.m3u   Встроенные плейлисты
CNAME                      Кастомный домен для GitHub Pages
```

## Локальный просмотр

С Docker:

```bash
docker compose up -d --build
# открыть http://localhost:999/
```

Без Docker — `python serve.py` (он отдаёт нашу `404.html` для неизвестных адресов). Обычный `python -m http.server 999` кастомную 404 не поддерживает, поэтому проверять редирект через него нельзя.

## Публикация

Это обычный статический сайт: опубликуйте содержимое корня репозитория через GitHub Pages (ветка `main`, корень `/`) или скопируйте файлы на любой статический хостинг. Файл `CNAME` задаёт домен `tv.dev4rev.ru`; `link[rel="canonical"]` в `index.html` указывает на него же.

В разметке внутренние пути записаны относительно (`./assets/...`), но `<base href="/">` привязывает их к корню домена: это нужно, чтобы ассеты и 404 работали и при fallback с вложенного адреса. Сайт рассчитан на публикацию в корне домена.

## Заметки

- Плейлисты «Шрек — весь цикл» и «Гарри Поттер — весь цикл» содержат официальные трейлеры, промо и тизеры с Internet Archive, а не полные фильмы: полные части недоступны как легальные прямые HTTPS-потоки.
- Плеер понимает `magnet:` и `.torrent` через локально встроенный WebTorrent (`assets/vendor/webtorrent.min.js`) и `sw.min.js`. Поддержка предназначена для легальных раздач с web-сидами: обычные TCP/UDP-торренты в браузере недоступны.
- В поле URL плейлиста есть скрепка: можно приложить один локальный `.torrent` и запустить его кнопкой «Загрузить». Файл отображается отдельной категорией «Файл». При первом запуске он сохраняется на время одного перезапуска Service Worker и восстанавливается автоматически.
- Обычный торрент без web-сидов и web-пиров в браузере не заработает: WebTorrent использует MediaSource и не умеет подключать TCP/UDP-пиров. Если web-сидов нет, плеер показывает процент загрузки, число пиров и отдельное уведомление «web-сидов нет».
- На мобильных (до 900 px) мини-плеер и кнопка «К плееру» отключены: они перекрывали слишком много контента.
- Подсказка «Поддерживаемые ссылки» переносится в `<body>` и позиционируется фиксированно, поэтому её не перекрывают шапка и кнопки плеера.
- На мобильных (до 720 px) шапка всегда компактная: ТВ-кнопка скрыта, «Кинотеатр» показан иконкой. Фиксированные панели привязаны к визуальному вьюпорту, чтобы кнопки не уезжали вправо после выхода из fullscreen.
- На сенсорных экранах верхний ряд управления плеером не скрывается при автозатухании контролов: кнопка панели «Плейлисты и каналы» остаётся доступна для касания.
- На мобильных выдвижная панель встроена внутрь плеера (внутри `.player__video-wrap`), а не в весь экран. Поэтому она одинаково работает в обычном и полноэкранном режиме, в том числе в ТВ-режиме; пока панель открыта, окно видео увеличивается до 76% высоты экрана.
- Универсальная адаптация: `viewport-fit=cover` и safe-area для выреза камеры/скруглений/нижнего индикатора, поля ввода не мельче 16 px (без автоматического zoom в iOS), увеличенные области нажатия для служебных кнопок, отдельные правила для узких телефонов (320–430 px), планшетов (721–1024 px) и короткого ландшафта. Для старых браузеров без `dvh` есть fallback на `vh`.
- Политика `privacy.html` составлена с учётом 152-ФЗ и требований РКН: указан оператор (dev4rev, @dev4rev), правовые основания, права субъекта, сроки хранения и порядок отзыва согласия. На всех страницах при первом входе показывается компактная плашка с «Принимаю» / «Отклонить» и ссылкой на политику (`assets/js/consent.js`).
- Есть отдельные страницы `privacy.html` (ссылка в футтере) и `404.html` в стиле «потерянного сигнала». Публичные адреса — **`/privacy` и `/404` без `.html`**: файлы остаются на диске, а расширение убирают `.htaccess` (Apache), `nginx.conf` (локальный preview) и `serve.py` (запуск без Docker). Старые адреса с `.html` продолжают работать. Для Apache используется `ErrorDocument 404 /404.html`, для nginx — `error_page 404 /404.html`. Клиентский guard в `index.html`/`theme-init.js` дополнительно перенаправляет на `/404?from=...`, если хостинг возвращает `index.html` (SPA-fallback). Исходный адрес показывается на странице ошибки. В `index.html` и `404.html` добавлен `<base href="/">`, чтобы относительные пути к ассетам работали и при fallback с вложенного адреса.
- При первом включении торрент-канала страница один раз перезагружается, чтобы Service Worker начал управлять страницей; плейлист и канал восстанавливаются автоматически.
- Живая подсветка читает цвет кадра только у CORS-доступных видео (потоки через MSE/hls.js, локальные и торрент-файлы). Для прямых MP4 без CORS используется цветовая палитра подборки.
- Прямые ссылки на потоки живут внутри M3U-файлов; сайт не делает запросов к внешним API и не загружает плейлисты во время работы, кроме выбранного пользователем.
- В плейлистах встречаются публичные ссылки с параметром `password=...` — это параметры самих потоков, а не секреты проекта.
- Внешние иконки карточек загружаются с Iconify (Lucide); при недоступности CDN используется локальный SVG-фолбэк.
